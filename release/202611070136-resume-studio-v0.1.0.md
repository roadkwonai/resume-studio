# Resume Studio 0.1.0

이력서와 포트폴리오 자료를 바탕으로 개인 웹 이력서를 독립 프로젝트로 만들고 검수하는 첫 릴리스입니다.

## 주요 기능

- 여섯 가지 템플릿의 갤러리와 `resume-portfolio` 스킬을 제공합니다.
- 새 포트폴리오는 Resume Studio 저장소 밖의 독립 폴더에 생성합니다. 기존 폴더는 덮어쓰지 않으며, 개인 프로필과 사진·PDF·환경 파일은 기본적으로 Git에서 제외합니다.
- 기존 웹 이력서를 재현할 때 화면과 프로젝트, 이미지, 링크, PDF 및 문의 기능을 함께 확인하는 절차를 제공합니다.
- 생성 프로젝트에 `.env.example`을 포함해 Gmail, Resend 및 Vercel 설정에 필요한 값을 안내합니다.
- 문의 방식과 배포 환경, 자료의 모호하거나 충돌하는 내용은 작업 중 확인하고, 원본과 실제 화면을 대조하는 검수 절차를 추가했습니다.

## 사용 전 확인

- Node.js 24가 필요합니다.
- 기본 문의 폼은 템플릿에 따라 이메일 앱을 엽니다. `.env.example`을 채우는 것만으로 서버 메일 발송이 활성화되지는 않습니다. Gmail 또는 Resend 연동은 별도로 구현하고 설정해야 합니다.
- Git에서 제외한 프로필과 이미지는 Git 기반 배포에 자동으로 포함되지 않습니다. 배포할 파일과 전달 방식을 별도로 확인하세요.
- 이력서 PDF와 프로젝트 이미지는 웹에 게시하면 방문자에게 공개됩니다. 공개할 자료를 확인하세요.

## 검증

독립 프로젝트 생성, 기존 경로 보호, 개인정보 Git 제외 설정, 빌드 및 화면 검수 절차를 점검했습니다. 사용자의 자료와 사용 환경에 따라 생성 결과는 다시 확인해야 합니다.
